# engine-facts

Starts empty; the user fills it, and it grows via the cache-miss ratchet
(missing information is fetched once, distilled, written here, and never
fetched again). Planned files: allocation.md, rendering.md, physics.md, ui.md.

For the block format and fields (FACT / THRESHOLD / LIMIT / INVERSE / SOURCE),
the canonical example is `../examples/05-engine-fact.md`. ~70-100 tokens per
block; no tutorial text, intro paragraphs, or sample code; the Unity version
is pinned; the INVERSE field is mandatory.
